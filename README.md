## Selected projects

### [Mr. French · Conversational AI](https://github.com/hassaanyousafzai/mr-french)
A conversational assistant for parent and child workflows, with task tracking, reminders and stored conversation context.

**Engineering focus:** connecting conversations to structured actions while keeping chat context and task data in separate stores.

**Stack:** Python · FastAPI · OpenAI · ChromaDB · Supabase · APScheduler

### [LibrArea · Bookshelf Recognition](https://github.com/hassaanyousafzai/LibrareaProject)
Turns a bookshelf photo into a digital book inventory. The pipeline detects book spines, extracts titles and authors, retrieves book metadata and produces shelf reordering instructions.

**Engineering focus:** combining object detection, OCR and external APIs in one image-processing workflow.

**Stack:** Python · FastAPI · YOLO11 · OpenCV · Gemini · Google Books API

### [Shifa Health · Bilingual Voice Agent](https://github.com/hassaanyousafzai/Bilingual_Hospital_Voice_Agent)
An English and Arabic hospital demo covering appointment booking and post-appointment feedback, with a dashboard for reviewing feedback.

**Engineering focus:** tool-driven booking, bilingual voice interaction and structured feedback analysis. Uses mock hospital data.

**Stack:** Next.js · TypeScript · FastAPI · Groq · SQLite

### [Data Analyst Agent · CSV to Insights](https://github.com/hassaanyousafzai/data_analyst_agent)
A sequential agent workflow: an analyst examines a CSV, a visualizer generates a chart and a writer summarizes the output.

**Engineering focus:** passing useful outputs between specialized agents across an analysis workflow.

**Stack:** Python · Groq · Gradio · Matplotlib
